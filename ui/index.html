      L'autre PC n'apparaît pas ?

      1. Lancez Inter Disk sur les deux PC.
      2. Vérifiez que le câble RJ45 est branché des deux côtés : les voyants de la prise doivent s'allumer.
      3. Sans box entre les deux, Windows met jusqu'à 1 minute à donner une adresse au câble (169.254.x.x). Patientez un peu.
      4. Pare-feu : déjà réglé avec InterDisk-Setup.exe. Avec la version portable, cochez aussi « Réseaux publics » ou lancez autoriser-pare-feu.bat.
      5. En Wi-Fi, les deux PC doivent être sur le même réseau. Les réseaux « invités » bloquent souvent les échanges.
      6. Sinon, utilisez Ajouter par adresse IP avec l'adresse affichée sous le nom de l'autre PC.
